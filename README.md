# Pickify — E-Commerce Web App

Pickify is a full-stack e-commerce web application built with Bootstrap, Vanilla JS and Laravel. The platform showcases dynamic product categories, an intuitive shopping cart workflow, customer testimonials, and a comprehensive backend system for managing inventory, orders, and user interactions securely.

---

## 🚀 Features

- 🛒 **Product Catalog & Filtering:** Dynamic display of products categorized by type with search capabilities.
- 🛍️ **Interactive Shopping Cart:** Real-time item additions, quantity adjustments, and value calculations.
- 💬 **Client Testimonials:** Dynamic carousel display of customer feedback and ratings.
- 🔐 **User Authentication:** Secure registration, login, and customized profile management.
- 🛠️ **Admin Management:** Backend CRUD operations for tracking orders, handling product stock, and monitoring contacts.
- 📦 **Order Processing:** Seamless checkout simulation and order tracking history.
- 📱 **Fully Responsive Design:** Optimized UI/UX across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

### Frontend
- HTML5 / CSS3 / JavaScript (ES6+)
- Bootstrap / SCSS
- Swiper.js (for Testimonial/Product sliders)

### Backend
- Laravel
- Eloquent ORM & Authentication Guards

### Database
- MySQL
